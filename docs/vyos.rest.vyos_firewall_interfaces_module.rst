**********************************
vyos.rest.vyos_firewall_interfaces
**********************************

**Firewall interfaces resource module via REST API.**


Version added: 1.0.0

.. contents::
   :local:
   :depth: 1


Synopsis
--------
- Attaches or detaches named firewall rule sets to/from interface directions (in/out/local) using the VyOS HTTPS REST API.
