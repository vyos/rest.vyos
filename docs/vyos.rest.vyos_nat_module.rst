******************
vyos.rest.vyos_nat
******************

**Manage NAT configuration on VyOS devices using REST API**


Version added: 1.0.0

.. contents::
   :local:
   :depth: 1


Synopsis
--------
- Manages NAT configuration on VyOS devices via the REST API.
- Supports source, destination, static, CGNAT, NAT64, and NAT66.
- Uses REST API (``connection=httpapi``) instead of CLI.
- Targets VyOS 1.5+.

Examples
--------

.. code-block:: yaml

    - name: Merge source NAT rule
      vyos.rest.vyos_nat:
        config:
          nat:
            source:
              rule:
                - id: 100
                  outbound_interface:
                    name: eth0
                  translation:
                    address: masquerade
        state: merged

    - name: Delete all NAT
      vyos.rest.vyos_nat:
        state: deleted

    - name: Gather NAT configuration
      vyos.rest.vyos_nat:
        state: gathered
