.. _vyos.rest.vyos_bgp_global_module:


*************************
vyos.rest.vyos_bgp_global
*************************

**Manage BGP global configuration on VyOS via the REST API.**


Version added: 1.0.0

.. contents::
   :local:
   :depth: 1


Synopsis
--------
- Manages BGP global parameters on VyOS devices using the HTTPS REST API.
- Mirrors ``vyos.vyos.vyos_bgp_global`` but uses the HTTP API.



Requirements
------------
The below requirements are needed on the host that executes this module.

- VyOS 1.3+
