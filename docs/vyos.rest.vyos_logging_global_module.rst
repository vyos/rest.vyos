*****************************
vyos.rest.vyos_logging_global
*****************************

**Manage syslog configuration on VyOS devices using REST API**


Version added: 1.0.0

.. contents::
   :local:
   :depth: 1


Synopsis
--------
- Manages syslog (logging) configuration on VyOS devices via the REST API.
- Targets VyOS 1.5+ syslog schema under ``system syslog``.
- Uses REST API (``connection=httpapi``) instead of CLI.

Examples
--------

.. code-block:: yaml

    - name: Merge logging configuration
      vyos.rest.vyos_logging_global:
        config:
          console:
            facilities:
              - facility: local7
                severity: err
          hosts:
            - hostname: 172.16.0.1
              port: 514
              facilities:
                - facility: local7
                  severity: all
          users:
            - username: vyos
              facilities:
                - facility: local7
                  severity: debug
          global_params:
            facilities:
              - facility: cron
                severity: debug
            marker_interval: 111
            preserve_fqdn: true
        state: merged

    - name: Delete all logging configuration
      vyos.rest.vyos_logging_global:
        state: deleted

    - name: Gather current logging configuration
      vyos.rest.vyos_logging_global:
        state: gathered
