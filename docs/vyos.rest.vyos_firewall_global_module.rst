******************************
vyos.rest.vyos_firewall_global
******************************

**Manage global firewall configuration on VyOS devices using REST API**


Version added: 1.0.0

.. contents::
   :local:
   :depth: 1


Synopsis
--------
- Manages global firewall group configuration on VyOS devices via the REST API.
- Covers address-groups, network-groups, port-groups, interface-groups, and IPv6 network-groups.
- Uses REST API (``connection=httpapi``) instead of CLI.

Notes
-----

.. note::
   - Requires ``ansible_connection=httpapi`` with the VyOS httpapi plugin.
   - ``ansible_network_os`` must be set to ``vyos.rest.vyos``.



Examples
--------

.. code-block:: yaml

    - name: Merge firewall global configuration
      vyos.rest.vyos_firewall_global:
        config:
          group:
            address_group:
              - name: SERVERS
                description: Web servers
                address:
                  - 192.168.1.10
                  - 192.168.1.11
            network_group:
              - name: LAN
                network:
                  - 192.168.0.0/16
            port_group:
              - name: WEB-PORTS
                port:
                  - "80"
                  - "443"
            interface_group:
              - name: LAN-IFACES
                interface:
                  - eth1
                  - eth2
            ipv6_network_group:
              - name: IPV6-LAN
                network:
                  - "2001:db8::/32"
        state: merged

    - name: Delete all firewall global configuration
      vyos.rest.vyos_firewall_global:
        state: deleted

    - name: Gather firewall global configuration
      vyos.rest.vyos_firewall_global:
        state: gathered
