****************************
vyos.rest.vyos_static_routes
****************************

**Manage static routes on VyOS via the REST API.**


Version added: 1.0.0

.. contents::
   :local:
   :depth: 1


Synopsis
--------
- Manages IPv4 and IPv6 static routes on VyOS devices using the HTTPS REST API.
- Mirrors ``vyos.vyos.vyos_static_routes`` but uses the HTTP API.



Requirements
------------
The below requirements are needed on the host that executes this module.

- VyOS 1.3+
