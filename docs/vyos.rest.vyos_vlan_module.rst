.. _vyos.rest.vyos_vlan_module:


*******************
vyos.rest.vyos_vlan
*******************

**Manage VLANs on VyOS network devices via REST API.**


Version added: 1.0.0

.. contents::
   :local:
   :depth: 1


Synopsis
--------
- Manages 802.1Q VLAN sub-interfaces on VyOS Ethernet interfaces using the HTTPS REST API.
- Mirrors ``vyos.vyos.vyos_vlan`` but uses the HTTP API.
