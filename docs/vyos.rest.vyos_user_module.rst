*******************
vyos.rest.vyos_user
*******************

**Manage local users on VyOS via the REST API.**


Version added: 1.0.0

.. contents::
   :local:
   :depth: 1


Synopsis
--------
- Manages local user accounts on VyOS devices using the HTTPS REST API.
- Mirrors ``vyos.vyos.vyos_user`` but uses the HTTP API.
