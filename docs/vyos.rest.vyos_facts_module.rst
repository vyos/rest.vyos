********************
vyos.rest.vyos_facts
********************

**Get facts about VyOS devices via REST API.**


Version added: 1.0.0

.. contents::
   :local:
   :depth: 1


Synopsis
--------
- Collects facts from VyOS devices using the HTTPS REST API.
- Returns system info and optionally per-resource configuration facts.
